**THE GAME:**  https://paulodavidhun.github.io/amoeba_online_1/

**HUN**
• Csak haverom megkérdezte hogy "AI-jal mennyi idő alatt lehet összerakni egy egyszerűbb online" játékot? 

  A válasz:kb 2-2,5 óra javításokkal.
  
• Ez egy egyszerű amőba ami ingyenes google adatbázis-ban tárolja a lépéseket és adja át az infót, és githubon tároljuk a kódelemeket. 

• Belépünk egy szobába, ott lesz egy kód, azt meg kell adni a másik játékosnak, aki ezzel a kóddal be tud lépni a "szobába".

• Egy szobában 2 ember lehet, akik egymás ellen játszanak.


**ENG**
• A friend of mine just asked me: "How long does it take to build a simple online game using AI?"

The answer: About 2 to 2.5 hours, including debugging and fixes.

• It is a simple Tic-Tac-Toe game that uses a free Google database to store moves and sync data, with the code components hosted on GitHub.

• Once you enter a room, you get a code. You need to share this code with the other player so they can join the same "room".

• Each room accommodates exactly 2 people playing against each other.
